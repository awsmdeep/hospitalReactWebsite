# **Integrated Healthcare Management System for Tata Motors Hospital**

## **Project Overview**
The Integrated Healthcare Management System is a full-stack web application developed to streamline hospital operations for Tata Motors Hospital. This system digitizes hospital processes, enabling efficient management of patient, doctor, and admin activities. It provides user-friendly dashboards, authentication mechanisms, and a comprehensive landing page showcasing the hospital's services.

---

## **Key Features**
- **User Authentication:** Secure login/signup for patients, doctors, and admins.  
- **Role-Based Dashboards:**  
  - **Patients:** Book appointments, view medical history.  
  - **Doctors:** Access patient details, manage schedules.  
  - **Admins:** Oversee hospital operations, manage doctors and patients.  
- **Landing Page:** Showcases the hospital's services, staff, facilities, and contact details.  
- **Responsive Design:** Seamlessly accessible across devices with an intuitive user interface.  

---

## **Tech Stack**
### **Frontend**
- **React.js:** For building a dynamic and interactive user interface.  
- **Tailwind CSS:** For responsive and modern design.  

### **Backend**
- **Node.js:** For server-side logic and API creation.  
- **MongoDB:** For database management and secure data storage.
